# 戦国VS 5.8.0 — 太政官の任命・解任

2026-11-27（日本時間）。画面releaseは `5.8.0-20261127`、APIは `5.8.0`。

## 変更した動作

- 太政大臣は運営アカウントの固定官職。外部官職APIの選択肢や解任対象に含めない。
- 運営のみが「京都御所 → 朝廷の役職 → 太政官の任命・解任」で他拠点の領主を検索し、6官職の空席へ任命・解任する。各職1名・1人1職。
- 京都御所の在任官職は選べない。京都昇進・役職変更・外部任命者のスタッフ化等で衝突した場合は、同じDBトランザクションで外部任命を解除する。空席化しても旧任命は復活しない。
- 確認時の一覧revisionと対象者IDを確定時に照合し、操作番号の再送で二重任命や古い任命の復活が起きないようにする。
- 公開名札・プロフィール・敬語判定へ官職を反映する。運営・スタッフ・拝謁応対・京都から江戸への出陣権限は従来の判定を維持する。
- 明示的に任命・解任を確認したときは、確認欄を見える位置へ移す。通常のpollは入力・IME・選択・フォーカス・表示位置を保つ。

## 配備

追加移行は `0039_external_court_offices.sql`。既存移行・journalエントリーは変更せず追加し、初期データの投入は認証済み管理APIで行う。配備アーカイブのSQLとjournalの末尾を確認した。

APIはSites version73、source `8bb953fd73d8d9c85dd5484006224262cfa7cd20` の公開が成功した。操作画面を公開する前に、公開APIのhealthが `status:"ready"`、`version:"5.8.0"`、`features.courtOffices:true` を返すことを実ブラウザーで確認した。フロントのPRチェック、Pages公開、実配信ファイル一致は公開時に確認する。

検証中に実プレイヤーの任命・解任や権限変更は行っていない。任命は公開後、運営が操作画面から行う。
