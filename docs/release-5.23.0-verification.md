## 実装した規則

地域は既存の9区分を使用する。周回境界の現在の領有状態で判定し、江戸城・京都御所・鹿児島城を条件から除外する。制覇地域では領有、城郭レベル、城壁、守備兵、耐久、城普請、支拠点を保持する。未制覇地域の本拠以外は従来どおり精算する。境界後も通常の時間経過と維持費は適用される。

継承城も各周回の領地精算報酬に含む。同じ周回の受付記録は再送・競合で重複せず、継承城の初攻略報酬も再取得できない。前回の継承履歴を保存するが、履歴から失った城を復活させることはない。

京都御所の正式加入は従五位・総合評価35,000点以上。確認された本拠と全占領領地を放棄し、継承履歴も消去する。個人資源・武将・研究・購入情報・個人施設の育成記録を保持し、城郭と施設は御所の共有状態を利用する。旧戦役のセーブから放棄した領地を復元することはできない。応答を失った場合は同じ受付番号で成立結果を確認する。
