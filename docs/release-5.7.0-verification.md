# 戦国VS 5.7.0 — 修復・守備台帳と資源計画の保存

2026-11-27（日本時間）。対象は `5.7.0-20261127`。

## 変更した動作

- 「城と内政」から、自領の城・支拠点の耐久、守備と配置兵、現在の資材だけでの修復見込み、生産・維持費を含めた次月の見込みを確認する。検索・絞り込み・並び替え・詳細への移動ができる。閲覧は資材や指令を消費しない。
- 資源計画を領主・戦役・本拠・役割の組に分け、同じ端末で最近6組まで復元する。保存失敗は入力を保って表示する。識別できない旧セーブでは永続化しない。
- 複数タブで計画を開き続けた場合、現在の画面で変更した項目だけを最新の有効な保存データへ統合する。同じ項目を双方で編集した場合は後の保存を採用する。
- 保存を待つ間に画面を移動した場合、古い「新版を開く」「保存してタイトルへ」の完了処理を取り消す。共通時刻未確認時には台帳の秒数も未確認として扱う。
