# 戦国VS：紹介導線と宣伝履歴の点検

点検日：2026-11-26（日本時間）

## 今回の点検と変更

- 紹介ページと素材ページで使用する `promotion-share.js` を確認。Clipboard APIを使えない場合のコピー成功後、ボタンを有効に戻してからフォーカスを復元するよう修正した。
- 選択APIの片方が使えない端末でも、もう片方が成功した場合はコピーを続行する。両方とも失敗した場合は別の古い選択範囲をコピーせず、欄内から手動コピーする案内を表示する。
- ネイティブ共有の対応判定で共有データが拒否される環境では、そのボタンを表示しない。X、LINE、URLコピーの導線は引き続き使える。共有をキャンセルした場合はエラー扱いにせず、再度操作できる。
- ダウンロード用の基本情報・投稿文・英語ファクトシートに、公式の更新情報とRSSへの入口を追加できるよう生成処理を更新。日付はサイトメタデータから生成する。
- `node tests/test-promotion-sharing.cjs` により、コピー権限拒否、選択API失敗、手動コピー案内、対応外共有、共有キャンセルと拒否を確認した。

XのリンクはWeb Intentの `text`、`url`、`hashtags` を使用。LINEのリンクは公式案内の共有URLへUTF-8でエンコードした `url` と `text` を渡す構成になっている。自動投稿・共有先の自動選択は行わない。これらの導線から実際に何人が共有したか・訪問したかは、この点検では計測していない。

LINE公式仕様：<https://developers.line.biz/ja/docs/line-social-plugins/install-guide/using-line-share-buttons/>
