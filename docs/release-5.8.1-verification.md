# 戦国VS 5.8.1 — PCの右クリック無効化と表示処理の軽量化

2026-11-27（日本時間）。フロントエンドreleaseは `5.8.1-20261127`。公開済み5.8.0を基点とする。

## 変更した動作

- PCのゲーム画面内で右クリックしても、ブラウザのコンテキストメニューを開かない。通常の本文・画像・ボタン・入力欄・ダイアログに適用し、タッチ対応PCのマウスも扱う。
- 通常のクリック、テキスト入力、キーボードのコピー・貼り付け、スライダー等は既存の操作を維持する。タッチによる入力欄の編集メニューは保持する。
- 体力・耐久ゲージが差分DOM索引を利用し、閉じたダイアログ、hidden/inert領域、タイトル裏、非表示タブの投影計算を省く。開いた画面では最新値へ追いつく。
- 背景タブに移った後はサムネイルから大型画像への追加取得・描画を保留し、表示復帰で再開する。閉じたダイアログでのサムネイル失敗による大型画像取得も保留する。

## 検証と測定

| 対象 | 確認内容 |
| --- | --- |
| PC右クリック | Chromeでタイトル本文、城下町、設定ダイアログ見出し、メニュー検索入力を実際に右クリックし、4件ともcontextmenuのdefaultPrevented=trueを観測。検索へ「軍団」を入力し、3件の結果表示まで確認。 |
| 入力操作 | selection-lock 8群。マウス、タッチ対応PC、入力欄、readonly、contenteditable、コピー・選択・キーボード・スライダー・選択肢を検証。 |
| メーター | live-meters 4群。追加・削除・属性変更の同一タスク反映、閉じて再表示、入力・選択・フォーカス・スクロール維持、サブツリー直接更新を確認。 |
| 体力・耐久既存UI | 各5群。実エンジンで値とDOM継続性を確認。 |
| 画像 | lifecycle 5群・refresh 15 PASS行。背景移行、復帰、閉じた画面、失敗時フォールバック、同じプレビューの再取得防止を確認。 |
| 配信 | build/check:build、entry、interface、source/minified継続性、配布容量を確認。 |
| 公開文書 | SEO、canonicalページのローカルリンク、RSS、プレスキット生成一致を確認。 |

計測用DOMでは、60回の体力・耐久更新に伴う全document走査は120回から0回、1更新の体力投影対象は261名から表示中の3名へ減少した。大型画像の試験は、非表示への切替後の要求が小型＋大型の2件から小型の1件へ減り、復帰後に大型を1回取得した。これらは処理回数とリクエストの計測であり、端末FPSや起動秒数の実測ではない。

実ブラウザ検証はメモリー内保存、模擬時計、外部API遮断のローカル環境で実施。実プレイヤーのセーブや領主設定は操作していない。デスクトップChromeでの確認であり、実機Safari/Firefoxの全操作を網羅するものではない。

## 配備範囲

フロントエンドと公開文書のみ。APIは公開済み5.8.0を使用し、Worker・DB移行は変更しない。同期と複数タブの復元記録は別更新として追加検証する。
