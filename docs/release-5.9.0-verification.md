# 戦国VS 5.9.0 — 予定・計画から詳細へ直結する操作改善

2026-11-27（日本時間）。フロントエンドrelease `5.9.0-20261127`。公開済み5.8.1を基点とする。

## 変更した体験

行動予定表の各普請・研究から、対象の施設・城・支城・研究を直接開く。研究は対象見出しへスクロールとフォーカスを移す。完了した工事や失った城など、クリック直前に条件が変わった対象は再確認して安全な既存画面へ戻す。同じ領主・戦役で予定表を開き直すと、検索・分類・表示件数・読書位置を保持する。日本語変換途中の入力では検索結果を差し替えず、Escapeは上に重なった画面だけを閉じる。

資源計画にも対象名付きの詳細ボタンを追加した。移動前に編集中の計画を保存し、時計の購読を解放する。同じ目標へ戻ると備蓄・予測の開閉とスクロール位置を保つ。自由入力や合計計画は単一の移動先がないため、対象直結ボタンを出さない。701〜900px幅では資源・備蓄のカードを2列にし、タブレットで説明が細く折り返されることを抑えた。

施設詳細では指令・資源・天守条件・普請枠の不足を明記する。天守へ進むボタン、普請の完成予定を見るボタンを状況に応じて表示する。既存の実行時の確認を維持し、残り時間の更新で理由が変わらなければテキストノードを置き換えない。

編成セットの比較内容を、実際の変更callback内でもう一度照合する。比較後に軍団・能力・所持・奉行・支城の配置が変わっていれば、最新の比較を提示し再確認を求める。削除されたセットは適用しない。

## 天下地図の計算

城の座標をx順に処理し、クラスタの左端から離れ過ぎた候補を距離比較前に除く。全メンバー間の距離制約、本拠・選択中の城の独立表示、従来の同順位の選択順を保つ。

| fixture | 従来の距離比較 | 改修後 |
| --- | ---: | ---: |
| 実際の129城、3画面幅・5ズーム・パン・閾値を組み合わせた135場面 | 179,771 | 71,299 |
| 互いに離れた128城 | 8,128 | 0 |

実地図fixtureでは約60%の距離比較削減。別途160件の境界距離・密集・同じx座標・順不同入力を独立した全探索実装と比較し、まとまりが一致した。これは演算回数の計測であり、端末FPSや表示秒数の実測ではない。

## 実行した検証

- `build` と `check:build`、`test:entry`。配信bundle・オフライン導線・公開文書・press kit生成一致を確認。
- `test:interface` は464 PASS行。予定表34、資源計画36、計画保存19、編成画面16、連続普請11など、対象の回帰を含む。
- 既存のworld-map16群、新しいclustering3群。ソース/縮小bundleは66公開globalと62の戦役継続checkpointで一致。
- 公開文書はSEO27チェック、9 canonicalページと940ローカルリンク/資産、15更新分のRSSを確認。
- Chrome実画面で、予定表の田畑検索→予約施設→資源計画→詳細→資源計画を操作。備蓄12,345、展開状態、スクロール位置を保持。予定表に戻った時の検索語保持と、研究見出しへのフォーカスも確認。成長手帳では編成名を入力し、保存→比較→確認して切り替えるまで実操作した。
- 390pxでは満員の商家から「普請の完成予定を見る」で普請3件に絞った予定表へ移動。320pxでは予定表→施設→計画と、Escapeで元の施設が残ることを確認。768pxと横844pxも操作し、ダイアログの横幅の超過や閉じるボタンの画面外配置がないことを確認した。

画面幅はChromeの同一origin iframeによる320×568、390×844、768×1024、844×390のレイアウト試験。実機のタッチ・ソフトウェアキーボード・Safari固有動作の全件試験ではない。試遊保存はメモリー内だけ、共通時計は模擬、外部APIを遮断し、実プレイヤーのデータを操作していない。編成の状態変化競合は実エンジンとDOMモデルによる回帰で検証した。

## 配信量と範囲

初期6bundleは3,309,958 raw bytes / 950,478 gzip bytes。5.8.1比で+11,264 / +3,341 bytes。上限は3,320,000 / 955,000と明示し、無制限の増加を許可しない。マップの実行時負荷削減と、新しい操作機能による配信量の増加を区別する。

API・DB移行なし。複数タブ保存の修正と、施設の完成後効果比較は別の更新単位として検証している。継続状況は[CONTINUATION.md](CONTINUATION.md)に記載する。
