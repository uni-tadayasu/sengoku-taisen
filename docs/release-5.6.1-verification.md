# 戦国VS 5.6.1 — 操作と表示の継続性

2026-11-27（日本時間）。公開先は既存の GitHub Pages。サーバー・資源計算・戦闘ルール・セーブ形式の変更はありません。

## 改善

- 城下町の全景と施設の位置を保ち、枠の余白を同じ風景の背景で補う。通常の景色と同じ responsive image を参照する。
- 施設アイコンを金色に修正。浮いた名称札が収まらないときは各ボタンに施設名を表示し、極小の絵では主要施設の操作一覧を出す。
- 信頼されたボタン・メニュー・タブ・チェック操作に一度だけ短い操作音。無効な操作、プログラムからのクリック、入力中、消音、通話中、非表示時は鳴らさない。既存の効果音音量を使用。
- 成長手帳を native dialog と安定した DOM 更新へ変更。タブ間の入力、編集中の文字、スクロール、キーボード操作を保持し、閉じた後の古い通信と別領主への応答を失効させる。
- 通常の同期が含む有効な共通時刻を再利用。同期が止まると7秒で専用取得へ戻り、15秒の確認期限は維持する。
- 独立した既存ダイアログの書体を衡山行書へ統一し、数値とコードは読みやすい専用書体を保持する。

## 検証

- build/check、entry、interface の既存・追加テスト。追加分は成長画面9件、操作音12件、共通時計12件。
- 城下町の40形状と名称の配置、44pxの操作領域、同じ形状の再利用。
- 入力・同期の継続性14件。設定、minified runtime、responsive text、press kit の一致検証。
- 初期bundle合計 3,117,043 bytes / gzip 889,624 bytes。既存予算 3,160,000 / 910,000 bytes 内。
- CUAで合成セーブを使用し、実サービスへの通信を無効化したChrome検証。1363×936で金色の施設と全景の位置、320×568で横溢れなし・native top layer・編成名のタブ往復保持・Escapeで元のメニューへフォーカス復帰を確認。844×390でも横溢れなし。
- 音量25%・BGM停止の合成設定で、開始・施設タブ・メニュー・成長タブの各操作が一回ずつ実際に効果音の再生成功へ到達することを確認。音の主観的な聴き取りと実機iOS/Androidの検証は含めない。
