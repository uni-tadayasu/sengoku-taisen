## 主な変更と使い方

### 交流の領主設定と各画面の見切れ

領主設定のカードが途中で切れる原因は、高さを制限したグリッド内で、装飾カードの行が縮み、本文が隠れる組み合わせだった。プロフィール全体を自然な高さのラッパーへまとめ、本文の1か所を縦スクロールする構造に変更した。写真、名前、武将、居住先、端末管理を読み進められ、写真の切り抜き編集、入力中の文字、選択範囲、フォーカス、本文のスクロール位置を保つ。

交流画面のヘッダーを詰め、機能タブを1列の横スクロールに整理した。機能を選択・再表示したときは選択中のタブを表示範囲へ入れ、定期更新では手動で移動したタブ位置を戻さない。長い領主名・役職は本拠とプロフィールで折り返す。

ゲーム内では、財政・徴兵・維持費の表、城詳細、領地一覧、建築説明、国盗りの検索、イベント・運営の数値、軍団・研究・招集結果、設定の選択欄を点検・修正した。重要な説明、金額の全桁、操作名を省略せず、必要に応じて列を減らす。地図、マーカー、画像の切り抜き、ドラッグ操作、ログの意図的な抜粋、既存の表の横スクロールは維持する。

公開ページでは、細い画面で主要ボタンが1文字幅に押し潰される配置、目次・読了時の案内、画像と文章の段組を修正した。ゲームへ戻る導線を残し、文字拡大・横向きの短い画面でも本文を読み進められる配置にした。

関連ソース：[social-mobile.css](../social-mobile.css)、[social-viewport.js](../social-viewport.js)、[field-responsive.css](../field-responsive.css)、[responsive-text.css](../responsive-text.css)、[public-luxury.css](../public-luxury.css)。

### チャットの返信とメンション

世界・同盟・フレンド・運営チャットに次を追加した。

- 発言の「返信」から引用先を選び、送信前に確認・解除できる。
- 「@ メンション」または本文の `@` から領主を選択できる。宛先は最大8人で、自分宛ては「あなた宛て」と表示する。
- 書きかけ、返信先、宛先は会話ごとに保持する。送信失敗、会話の切り替え、遅れて返る送信結果で別の会話の入力を消さない。接続する本人が変わった場合は、以前の個人用下書きを破棄する。
- スマホでは改行と「送信」ボタンを使用する。PCでは Enter 送信、Shift+Enter 改行。日本語変換の確定と候補選択で意図せず送信しない。
- 候補を開いた短い画面でも、返信内容、宛先、入力欄、送信操作を利用できる。候補操作時に入力フォーカスを不必要に移さない。

サーバーは返信先を同じ会話の閲覧可能な投稿に限定し、メンション先の存在と参加条件を検証する。同盟・フレンド・運営の権限を保存時と応答前にも確認する。削除された元発言の本文を返信へ保存せず、削除後は引用できない状態を返す。既存本文、300文字上限、5秒間の送信間隔は維持する。

加算移行 `0036_chat_replies_mentions` で既存投稿と旧クライアントを保持する。返信先は自動でメンションされず、本文に `@名前` と書くだけでは宛先指定にならない。このメンション機能は会話内の表示であり、外部通知やプッシュ通知を送る機能ではない。

仕様：[server/API_CONTRACT.md](../server/API_CONTRACT.md)、実装：[social-chat.js](../social-chat.js)、[social-chat.css](../social-chat.css)。

### 軽量化と生成手順

JavaScript/CSS の元ファイルを編集可能なまま残し、配信する6 bundle を固定バージョンの esbuild で圧縮する。既存の実行順、グローバル公開API、CSSの優先順を保持し、プロパティ名の変更や副作用の削除は行わない。

大きな一覧の差分更新は、16要素以上の兄弟要素の候補を索引化して、先頭からの繰り返し検索を減らした。地図はカメラだけを移動・拡大したときに、変化のない街道の描画データを再生成しない。選択、所有・通行条件、地域、拠点データが変わる場合は更新する。

| 配信6 bundle の合計 | 変更前 | v5.1.1 最終生成 | 削減 |
| --- | ---: | ---: | ---: |
| ファイルのバイト数 | 3,312,545 B | 2,841,838 B | 470,707 B（14.21%） |
| 個別 gzip の合計 | 864,518 B | 814,110 B | 50,408 B（5.83%） |

最終値は、返信・メンションとレスポンシブ修正を含む生成物の合計。画像・音楽・API応答を含むゲーム全体の容量ではなく、実端末での起動秒数やFPSの測定値でもない。容量ゲートの上限は raw 2,950,000 B、gzip 850,000 B で、両方を通過した。

生成・検証は次のコマンドで再現できる。

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run check:build
node tools/build-game-entry.cjs --stats
node tests/test-asset-budget.cjs
```

### 更新情報・SEO・紹介導線

公式の更新情報 `/news/` と RSS `/news/feed.xml` を追加した。v5.1.1 と過去3件の更新を、安定した記事リンクとガイドへの参照で読める。RSS のURLは表示・コピーできる。サイトメタデータ、構造化データ、正規8ページのナビゲーション、サイトマップ、紹介用テキストとプレスキットを更新した。

更新情報はゲーム開始を遮る画面として自動表示しない。紹介動画は初期読み込みで外部プレイヤーを自動取得する構成にせず、ユーザーの操作から閲覧する。Service Worker は新バージョンへ更新し、ニュースは接続時に新しい内容を確認し、保存済みのページはオフラインで利用できる。

紹介文・URLのコピーは、Clipboard API を使えない場合の選択・手動コピー案内、失敗後のボタン再利用、フォーカス復元を改善した。対応外のネイティブ共有は表示せず、共有の取り消しをエラーにしない。X・LINE の共有先選択と投稿操作は利用者自身が行う。

RSS・共有導線・素材更新が今回の紹介施策であり、RSS はSNS自動投稿ではない。既存YouTube紹介動画と過去の媒体送信は今回の新規実績に数えていない。4Gamer向けは原稿と送信要件の準備までで、送信していない。アクセス数・検索順位・掲載獲得の増加は未確認。

詳細：[宣伝履歴と今回の点検](promotion-audit-20261126.md)、[4Gamer向け未送信原稿](promotion-4gamer-20261126.md)。

## 既知の制限

- **既存スタッフ同期テストの失敗**：`node server/test-staff.mjs` は92行目の `/sync` で期待HTTP 200に対し、HTTP 409 `MAINTENANCE_REFRESH_REQUIRED` となる。旧フィクスチャに現行の `maintenanceAuthority`／`maintenanceRevision` 同期情報がないためで、変更前 `62b148fe` の `server/index.js` を使った独立実行でも同じ失敗を再現した。両方とも `sqlError:null`。このテストは成功件数に含めていない。新規チャット、権限、削除に関連する回帰は通過している。
- **公開後確認の範囲**：本番の配信ファイルとRSSは検証済み。実ユーザーとしてのチャット投稿は行っておらず、送信・権限・削除競合は隔離したAPIとテストで検証した。
- **実機の網羅性**：記載した幅・条件と実ソースの検査は完了しているが、全OS・全ブラウザ・全入力機器の組み合わせを保証する記録ではない。オンラインの実ユーザーデータで全状態を網羅したものではない。
- **効果測定**：サイズ削減は生成ファイルで確認した。実通信環境での起動時間、低性能端末のFPS、検索順位、告知による流入数の改善率は測定していない。
