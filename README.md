# 戦国大戦 ― 城と群雄の戦記

一城の志が、天下を動かす。PC・スマートフォンのブラウザで遊ぶ、オリジナルの戦国ストラテジーゲームです。タイトル画面をクリック・タップすると城下町へ進みます。

**公開版:** https://uni-tadayasu.github.io/sengoku-taisen/

**ゲーム一式:** https://github.com/uni-tadayasu/sengoku-taisen/archive/refs/heads/main.zip

## 収録内容

| 項目 | 種類・段階 | イラスト数 |
| --- | ---: | ---: |
| 武将 | 256名 × 8ランク | 2,048点 |
| 城郭 | 128城 × Lv.1〜32 | 4,096点 |
| 施設 | 64種類 × Lv.1〜32 | 2,048点 |
| 合計 | ランク・成長段階ごとの原画 | **8,192点** |
| オリジナルBGM | 16曲 | — |
| 武将ランク | D / C / B / A / S / SS / SSS / U | 専用枠8種類 |

256名全員に8ランクの絵巻があり、衣装・構図・装飾が変わります。城・施設はレベルに応じて建築が発展します。表示用の原画は32点ずつ256枚の画像シートにまとめ、必要なシートを遅延読込します。8,192個の同じ絵に枠だけを重ねた構成ではありません。対応表は `assets/art-manifest.json`、画像構成は [ARTWORK.md](ARTWORK.md) に記載しています。

武将は全国から256名を選抜した「群雄集結」シナリオです。人物・城の年代を横断し、能力・技能・所属・位置関係・戦闘をゲーム用に設定しています。収録方針と参考資料は [SOURCES.md](SOURCES.md) を参照してください。

## 遊び方

1. 「城下町」で施設を発展させます。「全64施設を管理」から生産・軍備・外交などの施設を選べます。
2. 資源・普請・研究は実時間で進みます。1倍速では60秒で1か月、20秒で指令が1回復します。1倍・2倍・4倍、一時停止を選べます。
3. 武将を登用・招集し、軍団を編成して兵を募ります。施設に奉行を任命すると内政を助けます。
4. 「天下地図」で隣接する城を選び、偵察・外交・出陣を行います。兵数・戦法を決め、戦力予測を確認して出陣します。
5. 自領の城は「城郭の拡張」でLv.32まで成長します。城郭と施設は別々のレベルを持ち、共通の普請枠を使用します。
6. 城・施設の詳細にある「32段階の姿」を開くと、スライダーで完成形を見比べられます。閲覧だけでは実際のレベルや資源は変わりません。

128城の統一が目標です。敵勢力も時間の経過に応じて動きます。タイトル画面・非表示タブでは時間を進めず、閉じていた間の時間も自動加算しません。天下統一の戦役は端末ごとのCPU対戦で、世界チャット・ギルド・フレンド・郵便は共通サーバーに接続します。

## 勾玉と武将招集

通常の内政には金銭・兵糧・木材・石材を使います。武将招集にはゲーム内で獲得する専用通貨「勾玉」を使います。現実のお金による購入機能はありません。

- 初期勾玉: 3,000。単発300、10連2,700。
- 毎月30、各城の初回攻略で120、任務報酬でも獲得します。
- 各ランクで全256名が等確率です。名鑑・排出率画面で対象を確認できます。
- 同じ人物でもランク違いは新しい絵巻です。同一人物・同一ランクの重複は勾玉50に変わります。
- 軍団と奉行の能力には、その人物の所持する最高ランクが反映されます。

| ランク | 排出率 |
| --- | ---: |
| D | 25% |
| C | 25% |
| B | 20% |
| A | 15% |
| S | 8% |
| SS | 4% |
| SSS | 2% |
| U | 1% |

10連に最低ランク保証や天井はありません。排出率は各回に適用します。勾玉消費・抽選結果・収集状況はまとめて保存し、保存に失敗した場合は抽選前の状態へ戻します。

## 交流と運営機能

画面の「交流」で領主名を登録すると、世界チャットを利用できます。ギルドを作成・加入すると所属ギルドのチャット、フレンドを双方承認すると1対1チャットが開きます。

運営登録がまだない場合、交流の「領主」から初回運営登録ができます。指定の運営キーはサーバーの環境変数だけに保存し、公開HTML・JavaScript・GitHubのソースには含めません。最初の運営登録が完了すると、他のプレイヤーにはキー入力欄を表示しません。API側も登録済みの運営IDを認証します。

運営は専用チャット、お知らせの編集、全員宛・個人宛のシステムメール、金銭・兵糧・木材・石材のプレゼント送付を利用できます。お知らせは画面上部を右から左へ流れ、一時停止と動きを抑える設定に対応します。ギフトはサーバーの受取記録とゲームセーブの受取台帳で二重受取を防ぎます。

**運営登録後は「領主データを書き出す」で通信IDを保管してください。** 運営権限は最初に登録した領主に結び付きます。別端末では領主データを読み込んで復元できます。ゲーム進行のセーブJSONと領主データのJSONは別ファイルです。

## ダウンロード・保存・音楽

ゲーム内「保存・設定」→「ゲーム本体をダウンロード」でGitHubのZIP配布を開きます。ZIPをすべて展開し、フォルダー内の `index.html` をPCのブラウザで開いてください。`assets` などのフォルダーも同じ場所に置きます。交流・お知らせ・郵便にはインターネット接続が必要です。

ゲーム進行はブラウザに自動保存します。「セーブデータを書き出す」で別端末へ移せます。公開URLとローカルファイル、別ブラウザの保存は別々です。スマートフォンでは公開URLを開き、必要ならホーム画面へ追加してください。OSのファイルプレビューではJavaScriptを実行できない場合があります。

公開版は本体と閲覧した画像をオフラインキャッシュします。まだ開いていない画像を含めてオフラインで使う場合は、全画像入りZIPを利用してください。

BGMは音符ボタンから有効にします。箏・三味線・笛・笙・太鼓などをイメージした、16曲の本作独自のWeb Audio合成曲です。画面に応じた自動選曲と音楽帳での手動選曲・音量調整に対応します。

## ソース構成

外部ライブラリやCDNに依存しないHTML/CSS/JavaScriptです。

- `index.html` / `styles.css` / `app.js`: 画面・操作・保存・レスポンシブ表示
- `engine.js`: リアルタイム内政・建設・城郭・戦闘・ガチャ・セーブ検証
- `officers-data.js`: 実名256武将・基本設定・参考資料
- `artwork.js` / `artwork.css`: 全8,192点の対応・遅延読込・8種の枠・オリジナルアイコン
- `boot.js` / `boot.css`: タイトル画面・共通ローディング
- `music.js`: 全16曲のWeb Audioシーケンサー
- `social.js` / `social.css` / `config.js`: 通信画面・API接続設定
- `sw.js` / `manifest.webmanifest`: ホーム画面追加・オフラインキャッシュ
- `assets/`: 武将・城・施設・城下町・紋章・OGP・アイコン
- `server/`: 通信Worker・D1スキーマの参照ソース
- `tests/`: ゲーム・収録数・UI・音楽・通信の検証
- `tools/`: イラスト対応表・ダウンロードZIPの生成

## 開発と検証

Node.js 24以降で、依存パッケージを追加せず検証できます。

```sh
node tests/test-engine.cjs
node tests/test-content.cjs
node tests/test-ui-helpers.cjs
node tests/test-music.mjs
node tests/test-social-ui.cjs
node server/test-social.mjs
node tools/build-art-manifest.cjs --check
```

ZIPの再生成（引数は絶対パス）:

```sh
node tools/build-download.mjs --dist /absolute/path/to/sengoku-taisen --out /absolute/path/to/downloads
```

## 公開とサーバー

`main` への反映後、GitHub Pagesのデプロイが成功すると公開版が更新されます。通信APIは別のWorkerとD1で動作し、`config.js` のURLへ接続します。サーバーの設定・移行は `server/README.md` と `server/API_CONTRACT.md` を参照してください。フロントエンドの公開はAPIのソースを自動デプロイしません。

APIは指定のGitHub Pages、`http://127.0.0.1:4173`、ローカルHTMLのOrigin、API自身からの接続を許可します。別の配信先を使うときはAPIの `SENGOKU_ALLOWED_ORIGINS` に正確なOriginを追加します。

本作の画面・テキスト・画像・楽曲は本プロジェクト用に制作しています。戦役の進行はローカル保存です。共通の世界地図でプレイヤー同士が戦うPvPやサーバー管理の対戦ランキングは現在の実装に含みません。
