# 衡山毛筆フォント行書 — ローカルWebフォント

書家・青柳衡山氏の「衡山毛筆フォント行書」Version 2.1を使用しています。2026年11月27日に次の一次資料と公式配布ファイルを確認しました。

- [武蔵システム公式配布ページ](https://opentype.jp/kouzangyousho.htm)：行書体、JIS非漢字・第一水準・第二水準、商用利用と配布物への収録についての説明。
- [作者の青二書道教室](https://www7a.biglobe.ne.jp/~kouzan/)：衡山フォントについてパブリックドメイン、著作権放棄、利用・改変を認める説明。
- [公式配布ZIP](https://opentype.jp/bin/KouzanGyousho.zip)：今回の原本。

## 利用条件

配布元は商用利用を含め制限がないと説明し、作者はパブリックドメインとして利用・改変を認めています。原本の著作者名「青柳衡山 / KouzanAoyagi」を派生フォントのnameテーブルへ維持しました。フォントは無保証です。作者の制作物を本ゲームのオリジナル書体とは扱いません。

Google FontsのYujiシリーズは比較候補として調査しましたが、本配布には含めていません。

## 変換と配信

原本ZIPとTTFのSHA-256・公式URLは [source.json](source.json)、配信WOFF2のサイズ・SHA-256・Unicode範囲は [manifest.json](manifest.json) に記録しています。

FontToolsで実際に輪郭がある字形と空白を分割し、WOFF2へ変換しました。字の輪郭は描き直していません。原本に多数含まれる輪郭のない仮の文字割当は公開範囲から除き、未収録の人名などが空白にならず端末のフォントへ切り替わるようにしています。古い不正な`gasp`余白と、不要なAATの`mort`テーブルを除いています。

基本のかな・記号・入口の文字・頻出文字を1ファイルにまとめ、残りは重複しない文字範囲で分割しています。CSSの`unicode-range`により、表示に必要なファイルだけを要求します。`font-display: swap`によりフォント待ちで本文を隠さず、未収録文字と読込失敗は端末の明朝へフォールバックします。外部のフォントサービスへの実行時通信は行いません。

本文はPCで18px、狭い画面で17pxを基本とし、既存の文字拡大設定を維持します。資源・能力値・費用入力などは桁を読み取りやすい数字用の書体を使用します。実際の読みやすさと折り返しはブラウザの最終確認で評価します。

## 再生成

Python 3、`fonttools`、`Brotli`を用意し、リポジトリのルートで以下を実行します。公式配布が変わってSHA-256が一致しない場合は停止するため、再取得した原本を確認してから記録を更新してください。

```sh
python assets/fonts/kouzan-gyosho/build.py
python assets/fonts/kouzan-gyosho/verify.py
```

公式ZIPを既に取得している場合は、`build.py`の第1引数にローカルのZIPパスを渡せます。生成時の`index.html`・`app.js`・`command-center.js`・`travel-ui.js`から基本セットの文字を選びます。変換したファイルはコミットして配信するため、利用者の端末で変換処理は走りません。
