# 戦国VS「はじめての3手」縦型紹介動画

制作日：2026年11月26日（日本時間）

城下町・武将・天下地図の実ゲーム画面から、初めて遊ぶ人へ操作の流れを伝える36秒の紹介です。撮影用デモ進行の静止画を動画内に配置し、ゆっくりした移動・拡大と大きな文字を重ねています。ゲームプレイの録画ではありません。全場面に「ゲーム画面による紹介・撮影用デモ」を表示しました。ナレーションはありません。

## 構成

| 時間 | 内容 |
| --- | --- |
| 0–4秒 | 戦国VS／あなたの一城から。町を育て、武将を率い、次の城へ。 |
| 4–12秒 | 城下町を育てる。田畑や商家で領国の土台をつくる。 |
| 12–20秒 | 武将を編成する。能力と役目を見比べ、自分の軍団を整える。 |
| 20–28秒 | 地図から、合戦へ。隣の城と戦況を確認し、軍師の助言を読む。 |
| 28–36秒 | 基本プレイ無料、端末だけのCPU戦役から始める手順、領主登録が必要な機能、任意課金、公式URL。 |

「基本プレイ無料」とあわせて「有料の外観アイテム・月額支援は任意」を表示しています。「端末だけで遊ぶ」は個人戦役の始め方として紹介し、対人・同盟・交易は領主登録後と区別しています。未確認の人気、人数、評価、報酬は使用していません。

## 再生成

Python 3、Pillow、FFmpeg、ffprobe、Noto CJKフォントを使用します。

```sh
python3 tools/build-first-steps-video.py
```

レイアウト確認画像だけを生成する場合：

```sh
python3 tools/build-first-steps-video.py --frames-only --proofs-dir /absolute/path/to/qa
```

生成スクリプトは投稿や外部送信を行いません。既存の24秒イラスト紹介動画とは別ファイルです。
