# 戦国VS 国内向け縦型紹介動画

制作日：2026年11月26日（日本時間）

## 目的と内容

国内の新規プレイヤーへ、作品名と「城下町を育てる・武将を編成する・城を攻める」という遊びの流れを24秒で伝える告知動画です。縦型動画のスマホ表示を優先し、大きな日本語文字とゆっくりした画面の寄り引きを使いました。主要な文言は映像に焼き込んであり、無音再生でも内容を読めます。ナレーションは含みません。

全場面に「公式イラストによる紹介」と表示しています。素材はゲームの公式イラストで、録画したゲームプレイではありません。終盤には「基本プレイ無料」と、別売りの外観アイテム・月額支援があることを併記しています。架空の利用者数・人気ランキング・評価・期間限定の訴求は使用していません。

| 時間の目安 | 内容 |
| --- | --- |
| 0–4秒 | 戦国VS／一城から、天下へ。 |
| 4–8秒 | 城下町を育てる／施設を整え、自分の領国を豊かに。 |
| 8–12秒 | 武将を編成する／役目と戦法を選び、自分の軍団をつくる。 |
| 12–16秒 | 城を攻める／次の一城へ、あなたの采配を。 |
| 16–24秒 | 無料開始、インストール不要、対応端末、公式URL、課金に関する補足 |

場面の境界には0.4秒のクロスフェードを使います。最後の画面は約8秒確保し、URLと利用条件を読める長さにしています。

## 再生成

必要なもの：Python 3、Pillow、FFmpeg（libx264とAAC）、ffprobe、Noto CJKフォント。標準のフォントパスはスクリプト先頭にあります。

```sh
python3 tools/build-promo-video.py
```

動画の前にレイアウトだけ確認する場合：

```sh
python3 tools/build-promo-video.py --frames-only --proofs-dir /absolute/path/to/qa
```

画像の縦横比を保って切り出し、カメラ移動・色付きの文字背景・文字を映像レイヤーとして重ねています。元のイラストを描き変える処理はありません。生成器は外部アカウントへの投稿や、公開・送信の操作を行いません。

## 完成版の確認結果

`ffprobe`で実測した完成版は **24.000秒・576フレーム・720×1280・24fps**。H.264 / yuv420pとAAC 44.1kHzステレオの2ストリームです。MP4の容量は **3,237,853バイト（約3.24MB）** で、6MB以下に収まっています。MP4のmoov atomがmdatより前にあり、faststartの配置も確認しました。

1・5・9・13・18・22秒の6フレームをMP4から抽出し、見出し、イラスト、公式URL、課金補足の文字切れと配置を目視確認しました。動画全体をFFmpegでデコードし、576フレームの読み取りが正常に完了しています。

完成版の音声は、sample peak **−9.8dBFS**、mean volume **−26.2dBFS**。−50dBFS以下が0.2秒以上続く区間は検出されませんでした。冒頭と末尾は意図したフェードです。音割れに相当する0dBFS超過はありません。数値はFFmpegのvolumedetect / silencedetectによるもので、配信先での音量調整後の値ではありません。
